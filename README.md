# Coming Soon Template

A simple, responsive coming-soon page built with plain HTML, CSS, and JavaScript.

## Customize

- Replace `[YOUR NAME]` in `index.html`.
- Set the launch time in the `datetime` attribute on the `time` element.
- Update the contact email in `index.html`.
- Adjust the page appearance in `style.css`.

The page works without JavaScript. The launch date remains visible if the browser
does not run `script.js`.
